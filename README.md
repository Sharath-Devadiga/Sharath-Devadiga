## 🚀 Featured Projects

### 🧠 [CacheUpp](https://cacheupp.com)

A full-stack social and community platform designed for college communities.

- Dual-database architecture using MongoDB and PostgreSQL
- Semantic search using MiniLM embeddings and pgvector
- REST APIs for feeds, forums, friendships, messaging, moderation, and notifications
- Real-time messaging and online presence using authenticated WebSockets
- JWT authentication and Zustand-based client state management
- Cloudinary-backed image processing

**Tech:** React · TypeScript · Node.js · Express · MongoDB · PostgreSQL · Prisma · pgvector · WebSockets

---

### 📚 StudyVerse

A collaborative study platform built around semester-scoped study rooms.

- Built a Turborepo monorepo using Next.js, Express, Socket.IO, Prisma, and PostgreSQL
- Implemented real-time channel-based collaboration
- Added membership authorization and owner-level permissions
- Implemented rate limiting, optimistic UI, retry handling, and reconnection support
- Integrated Gemini API for on-demand study discussion summaries
- Added PostgreSQL caching with bounded AI context

**Tech:** Next.js · TypeScript · Express · Socket.IO · PostgreSQL · Prisma · Gemini API · Turborepo

### ✍️ MoodBlog

A full-stack social blogging platform centered around mood-based content.

- Built mood-based text and image posts, likes, nested comments, and user profiles
- Implemented authenticated CRUD operations
- Added JWT authentication, bcrypt password hashing, email verification, and password reset OTP
- Integrated Cloudinary for image uploads
- Built optimistic like interactions using Zustand
- Developed a custom feed-ranking system using recency, engagement, and interaction signals

**Tech:** Next.js · TypeScript · Prisma · PostgreSQL · Zustand · Cloudinary
